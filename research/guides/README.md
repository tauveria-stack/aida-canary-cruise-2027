# Реєстр гідів та екскурсій українською/російською

## Призначення

Каталог зберігає публічні професійні пропозиції, де мову екскурсії можна підтвердити джерелом. Українська має перший пріоритет; підтверджені російськомовні пропозиції зберігаються окремо як запасні. Реєстр не є рейтингом і не означає рекомендації до бронювання.

## Статуси мови

- **UA-VERIFIED** — професійна сторінка, платформа бронювання або надійне джерело прямо зазначає проведення екскурсій українською.
- **UA-REPORTED** — конкретні туристи повідомляють, що екскурсія була українською, але актуальне професійне підтвердження не знайдене.
- **UA-UNCONFIRMED** — є непрямі ознаки володіння українською, але проведення турів цією мовою не підтверджене.
- Для російської ведемо аналогічні окремі поля; підтверджена російська не прирівнюється до підтвердженої української.

Самопрезентація може підтвердити лише те, що професіонал публічно заявляє відповідну мову/пропонує тур цією мовою; вона сама по собі не підтверджує якість. Відгуки оцінюються окремо.

## Правила запису

- Стабільний ID на кожного гіда/команду. Одна команда з кількома островами має один запис із переліком територій.
- Зберігати лише необхідні публічні професійні канали; не додавати приватні телефони, особисті профілі учасників закритих груп, паролі чи інші персональні дані.
- Для кожної ціни зазначати валюту, формат (за особу/групу/авто), дату перевірки й джерело; історичні ціни не видавати за чинні.
- Невідоме записувати як «не встановлено», а не домислювати.
- «Не виявлено у перевірених джерелах» щодо конфліктів не означає, що всі джерела перевірені або що ризиків немає.
- Не визначати політичні погляди, громадянство чи етнічність за іменем, мовою, походженням або місцем народження. Фіксувати лише конкретні відкриті висловлювання/документовані випадки, без прихованого профілювання.
- Перед бронюванням сімейної круїзної екскурсії письмово уточнювати портовий pickup/drop-off, гарантоване повернення до борту із запасом, тривалість, максимальну кількість учасників, дитяче крісло, сходи/фізичне навантаження, оплату й скасування.
