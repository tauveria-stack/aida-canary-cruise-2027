Оновлено: 2026-11-07. Статус: початковий реєстр, НЕ повний парсинг спільнот.

## Принципи
- Зберігаємо власні стислий виклад, посилання, дату, контекст, рівень перевірки, наслідки для маршруту. Не копіюємо масово чужі дописи, персональні дані учасників або матеріали закритих груп.
- Відгук туриста — свідчення досвіду, не гарантія актуальності цін, правил, графіків. Розклад лайнера й офіційні правила перевіряти за myAIDA/AIDA.
- Зміна маршруту лише після зіставлення доказів; додавання джерела саме по собі не змінює рекомендацію.
- Кожен висновок має дату перевірки та посилання на джерело. Не називати неперевірені матеріали перевіреними.

## Записи доказів

### FV-001 — Самостійна екскурсія як робочий сценарій
- **Порт:** Puerto del Rosario, Фуертевентура; наш день 2027-01-07.
- **Теза:** самостійне дослідження острова/порту є реальною альтернативою екскурсії круїзної компанії.
- **Підстави:** CRUISE-REPORT, CRUISE-PORT; додатково CRUISE-FORUM-DE має тему про Mietwagen Tour.
- **Рівень:** підтверджено існування варіанта; не доведено, що він оптимальний для нашої сім'ї.
- **Вплив:** маршрут Puerto del Rosario → Guise y Ayose → Betancuria → Ajuy → порт залишається базовим до порівняння конкретних гідів/прокату.
- **Відкриті питання:** доступність авто на 07.01.2027, фактичні години отримання, дорожні умови, доступність Ajuy, буфер повернення до 19:30.

### TM-001 — TravelMamaClub як джерело сімейного досвіду
- **Теза:** спільнота створена для обміну практичними порадами досвідчених і нових сімейних мандрівників.
- **Підстава:** TM-INTERVIEW.
- **Рівень:** підтверджено загальну характеристику клубу; не отримано конкретних дописів про Канари.
- **Вплив:** використовувати як майбутнє джерело маршрутних нюансів, але не змінювати рішення без конкретного перевіреного допису.

1. Уточнити актуальний URL Navimba та конкретні теми по Fuerteventura, Madeira, Lanzarote, Gran Canaria, Tenerife.
2. Уточнити точну Facebook-групу TravelMamaClub; перевірити, які публічні дописи доступні без авторизації.
3. Для кожного знайденого релевантного допису створити окремий запис із датою подорожі, умовами, джерелом, практичним висновком та ступенем перевірки.
4. Порівняти конкретні пропозиції гідів із самостійним авто без автоматичної зміни базового маршруту.

- **Порт/локація:** Puerto del Rosario; La Oliva, El Cotillo, Betancuria та оглядові точки.

- **Зміст:** автор описує маршрут із кількома зупинками, чергу в прокаті, вітер на узбережжі та завантаженість Morro Velosa. Згадує плутанину з форматом координат.
- **Витрати/час:** Cicar Opel Corsa за €55 та альтернативна машина приблизно за €50 — історична ціна. Загальна тривалість не вказана.

### NAV-FV-004 — Особистий маршрут через Betancuria й Ajuy, січень 2020
- **Порт/локація:** Puerto del Rosario → Morro Velosa → Betancuria → Ajuy → Sicasumbre → Salinas del Carmen → Caleta de Fuste.
- **Джерело:** [допис у звіті про AIDAcara](https://navimba.com/viewtopic.php?p=817468#p817468), від 2020-02-28; звіт про круїз січня 2020.
- **Тип:** особистий досвід; поїздка компанією мандрівників.
- **Зміст:** заброньований Seat Arona замінили на Opel Zafira; прокат був біля круїзного порту. Карта маршруту показувала 137 км і 2 год 34 хв руху без зупинок.
- **Витрати/час:** €57,16 — історична ціна бронювання. Фактичний час дня, стоянки та повернення не наведені.
- **Надійність:** висока для факту поїздки й заміни класу авто, середня для здійсненності маршруту за день, низька для ціни 2027.
- **Практична цінність:** незалежний приклад, що Betancuria та Ajuy об'єднували в один круїзний день на авто. Це насичений приклад, а не вимога змінювати наш базовий маршрут.

- **Практична цінність:** автобус до Betancuria не вважати підтвердженим без окремої перевірки.

### NAV-LZ-001 — Насичений маршрут Лансароте
- **Порт/локація:** Arrecife → Timanfaya → Charco de los Clicos → Los Hervideros → соляні поля → виноградна долина → Haría / оглядові майданчики → Mirador del Río → Jameos del Agua → кактусовий сад.
- **Джерело:** [маршрутна порада у звіті про AIDAcara](https://navimba.com/viewtopic.php?p=815898#p815898), 2020-02-26.
- **Тип:** порада з попереднього досвіду; у звіті є описи особистої поїздки в січні 2020.
- **Зміст:** радять їхати до Timanfaya зранку; автор не встиг на кактусовий сад у попередній поїздці. Автор також описав відвідування півночі острова окремо, тож повний список не є маршрутом, який підтверджено як виконаний за одну круїзну стоянку.
- **Витрати/час:** сумарний час/кошторис не наведені; квитки й графіки об'єктів перевіряти офіційно.
- **Надійність:** середня для вибору пріоритетів, низька для поточних цін і черг.
- **Практична цінність:** пасажирам краще мати скорочений варіант і запас часу.
