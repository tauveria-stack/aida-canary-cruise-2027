## Принципи
- Зберігаємо власні стислий виклад, посилання, дату, контекст, рівень перевірки, наслідки для маршруту. Не копіюємо масово чужі дописи, персональні дані учасників або матеріали закритих груп.

- Зміна маршруту лише після зіставлення доказів; додавання джерела саме по собі не змінює рекомендацію.
- Кожен висновок має дату перевірки та посилання на джерело. Не називати неперевірені матеріали перевіреними.

## Записи доказів

### FV-001 — Самостійна екскурсія як робочий сценарій
- **Порт:** Puerto del Rosario, Фуертевентура; наш день 2027-01-07.
- **Теза:** самостійне дослідження острова/порту є реальною альтернативою екскурсії круїзної компанії.
- **Підстави:** CRUISE-REPORT, CRUISE-PORT; додатково CRUISE-FORUM-DE має тему про Mietwagen Tour.
- **Рівень:** підтверджено існування варіанта; не доведено, що він оптимальний для нашої сім'ї.
- **Вплив:** маршрут Puerto del Rosario → Guise y Ayose → Betancuria → Ajuy → порт залишається базовим до порівняння конкретних гідів/прокату.
- **Відкриті питання:** доступність авто на 07.01.2027, фактичні години отримання, дорожні умови, доступність Ajuy, буфер повернення до 19:30.

### TM-001 — TravelMamaClub як джерело сімейного досвіду
- **Теза:** спільнота створена для обміну практичними порадами досвідчених і нових сімейних мандрівників.
- **Підстава:** TM-INTERVIEW.
- **Рівень:** підтверджено загальну характеристику клубу; не отримано конкретних дописів про Канари.
- **Вплив:** використовувати як майбутнє джерело маршрутних нюансів, але не змінювати рішення без конкретного перевіреного допису.

## Черга дослідження
1. Уточнити актуальний URL Navimba та конкретні теми по Fuerteventura, Madeira, Lanzarote, Gran Canaria, Tenerife.
2. Уточнити точну Facebook-групу TravelMamaClub; перевірити, які публічні дописи доступні без авторизації.
3. Для кожного знайденого релевантного допису створити окремий запис із датою подорожі, умовами, джерелом, практичним висновком та ступенем перевірки.
4. Порівняти конкретні пропозиції гідів із самостійним авто без автоматичної зміни базового маршруту.
