# Дослідження туристичних спільнот

Цей каталог призначений для стислих тематичних нотаток із форумів, клубів і відгуків мандрівників. Публічний реєстр доказів і рішень: [community-sources.md](../community-sources.md).

## Структура

- Один файл на острів, порт або сталу тему, наприклад fuerteventura.md, madeira-funchal.md, tenerife.md.
- [research-log.md](research-log.md) містить дату, точний обсяг перегляду й теми, щоб не повторювати роботу.
- У кожному записі: місце, короткий переказ, пряме посилання, дата допису/подорожі, тип джерела, ціна/час лише якщо вони є в джерелі, достовірність, прогалини та практичний висновок.
- Не копіювати цілі пости, приватні дані, імена/контакти учасників або матеріали закритих груп.
- Розділяти фактичні деталі та враження. Старі ціни, розклади й правила позначати як історичні.
- Нова думка не змінює затверджений маршрут автоматично: рішення оновлюється лише після достатньої перевірки.
